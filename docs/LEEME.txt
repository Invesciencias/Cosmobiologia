Cómo subir y mantener este repositorio
======================================

Estructura (ver también README.md en la raíz):

  Raíz: index.html, explorador.html, evaluacion.html, README.md, LICENSE, CITATION.cff
  laboratorio/   El Laboratorio de las tres compuertas y su panel
  codigo/        Todo el código Python
  datos/         Datos de entrada (GCMT, partidas de ajedrez, Oklahoma)
  resultados/    Tablas de resultados
  docs/          Documentación
  js/            data.js, features.js y translations.js (los lee el explorador)
  imagenes/      Logo, favicon e íconos, y la animación de la portada
  licencias/     LICENCIAS.md (fuentes y créditos) y texto de CC BY 4.0
  .github/       Formulario de registro de hipótesis

Para subir cambios desde la interfaz web de GitHub:

1. Entra a https://github.com/Invesciencias/Cosmobiologia
2. "Add file" -> "Upload files". Arrastra los archivos. Para que queden en una
   carpeta, arrastra la carpeta completa, o al crear un archivo nuevo escribe
   la ruta con barras (por ejemplo: datos/archivo.csv).
3. Escribe un mensaje de commit y confirma "Commit directly to the main branch".
4. Espera 1-2 minutos y recarga https://invesciencias.github.io/Cosmobiologia/
   con Ctrl+F5.

El explorador necesita que js/, datos/ y resultados/ conserven sus nombres, porque las páginas los
cargan por ruta. Si abres explorador.html con doble clic en tu computador, los
navegadores bloquean fetch() de archivos locales (los tableros de ajedrez y la
tabla precargada no cargan); en GitHub Pages, servido por https://, sí cargan.
