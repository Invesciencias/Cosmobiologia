# datos/

Datos de entrada que usan el explorador y el Laboratorio.

- `eventos_gcmt_mecanismo.csv`, `eventos_gcmt_marea.csv`: sismos GCMT Mw ≥ 6, 1976–2026 (6.035). Son el *conjunto de descubrimiento*: no sirven como réplica independiente.
- `chess_games/`, `oklahoma_game_data.json`: casos didácticos del explorador.
